លេងរែក V20

បន្ថែម Game Mode:
1. រែកធម្មតា
   - កងទ័ពអាចដើរ និងរែក
   - កងទ័ពអាចរែកស្តេច -> ឈ្នះ
   - ស្តេចមិនអាចដើរ
   - គ្មានព័ទ្ធ
   - កងទ័ពអស់ -> ចាញ់
   - ប្រព័ន្ធហៅរែករក្សាជាមុខងារដាច់ដោយឡែក

2. រែកព័ទ្ធ
   - រក្សាច្បាប់រែកព័ទ្ធដែលមានស្រាប់
   - ស្តេចដើរ/រែក/ព័ទ្ធ
   - មានច្បាប់ព័ទ្ធ និងហៅរែក

នៅពេលចុច "លេងរែក" អ្នកនឹងឃើញផ្ទាំងជ្រើសប្រភេទរែក។
