លេងរែក V8 — កែច្បាប់រែក

ការរៀបកូន និងការចេញដំបូងរក្សាតាម V7 ដែលអ្នកបានបញ្ជាក់ថា 100% ត្រឹមត្រូវ។

ច្បាប់រែកដែលកែ:
1. បន្ទាប់ពីកូនមួយដើរចូលក្រឡាថ្មី ទើបពិនិត្យរែកនៅ "ក្រឡាថ្មី" នោះប៉ុណ្ណោះ។
2. បើមានសត្រូវនៅខាងឆ្វេង និងស្តាំជាប់គ្នា -> រែក ២។
3. បើមានសត្រូវនៅខាងលើ និងខាងក្រោមជាប់គ្នា -> រែក ២។
4. បើមានសត្រូវតែម្ខាង -> មិនរែក។
5. មិនសម្លាប់កូនផ្សេងទៀតនៅជិតទេ។
6. បើមួយក្នុង ២ ដែលត្រូវរែកជាស្តេច -> ភាគីម្ខាងនោះចាញ់ភ្លាម។
7. មុខងារព័ទ្ធនៅតែដកចេញក្នុង V8 ដើម្បីសាកល្បងរែកឱ្យត្រឹមត្រូវសិន។


## V9 — មូលហេតុដែល V8 មិនរែក
