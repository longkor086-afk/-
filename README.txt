លេងរែក V16 — ហៅរែកអាសាបង់

V16 រក្សាច្បាប់ V15 ទាំងអស់។

កែចំណុចសំខាន់:
- អាចបើកមុខងារ «ហៅរែក» មុនដើរ។
- ត្រូវដើរកូនទ័ពគោលដៅសិន ទើបប្រព័ន្ធចាប់ផ្តើមពិនិត្យ។
- ហៅបានតែកន្លែងដែលកូនទ័ពទើបដើរចូល។
- បើមានកូនគូប្រកួតអាចមករែក -> ហៅរែកដំណើរការ ហើយគូប្រកួតជ្រើសកូនដែលអាចមករែក។
- បើគ្មានកូនគូប្រកួតអាចមករែក -> «ហៅរែក» អាសាបង់។
- ករណីហៅរែកអាសាបង់ មិនបង្ខំឱ្យគូប្រកួតរែកទេ។
- គូប្រកួតនៅតែមានវេនធម្មតា អាចដើរកូនផ្សេងតាមធម្មតា ឬប្រើយុទ្ធសាស្ត្រផ្សេង។
- រែក, ព័ទ្ធ, ស្តេច និងច្បាប់ចេញដំបូងរក្សាដដែល។
