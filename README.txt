លេងរែក V3

កែតម្រូវបន្ថែម:
- ការចេញដំបូងជាគូ ២ កូន ដោយរំលងមួយក្រឡា: ១&៣, ២&៤, ៣&៥ ... ៨&៦ តាមទិសដែលអាច។
- ភាគីទីពីរធ្វើដូចគ្នា។
- បន្ទាប់ពីការចេញដំបូងចប់ ចូលលេងធម្មតា មួយកូនម្តង។
- រែកកើតតែនៅក្រឡាដែលកូនទើបដើរចូល ហើយសម្លាប់តែ ២ កូននៅសងខាង។
- រែកបានទាំងផ្ដេក និងបញ្ឈរ។
- បើរែកស្តេចបាន គូប្រកួតចាញ់។
- បន្ថែមច្បាប់ព័ទ្ធ៖ បើកូនគូប្រកួតព័ទ្ធទាំង ៤ ទិសដោយគ្មានប្រឡោះទំនេរ កូនស្លាប់; បើស្តេចត្រូវព័ទ្ធ ចាញ់។
