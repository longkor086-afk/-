លេងរែក V5

- ខ្មៅ = ស្តេច ១ + កូនទ័ព ១៥ = ១៦។
- ស = ស្តេច ១ + កូនទ័ព ១៥ = ១៦។
- ដំបូងជ្រើសកូន ២ ក្នុងពេលតែមួយ។ កូនត្រូវស្ថិតលើជួរដូចគ្នា និងមាន ១ ក្រឡារវាង (ឧ. ១&៣, ២&៤)។ កូនទាំងពីរចេញជាមួយគ្នា។
- បន្ទាប់ពីដំណាក់កាលដំបូង ចូលលេងធម្មតា មួយកូនម្តង។
- រែកកើតតែនៅក្រឡាដែលកូនទើបដើរចូល និងត្រូវមានគូប្រកួតនៅសងខាងទាំងពីរ។ សម្លាប់តែ ២។
- រែកបានទាំងផ្ដេក និងបញ្ឈរ។ រែកស្តេច = ឈ្នះ។
- ព័ទ្ធពិនិត្យ ៨ ក្រឡាជុំវិញ។ បើនៅសល់ក្រឡាជាប់ទំនេរមួយ ឬច្រើន = រស់; បើគ្រប់ ៨ ទិសជាប់/គែម = ស្លាប់។ ស្តេចត្រូវព័ទ្ធ = ចាញ់។
