លេងរែក V17 — ប៊ូតុងហៅរែកតែមួយ

កែតាមការបញ្ជាក់ចុងក្រោយ:
1. លុបប៊ូតុង «បន្ត (មិនហៅរែក)» ចេញទាំងស្រុង។
2. ទុកតែប៊ូតុង «🪤 ហៅរែក»។
3. ប៊ូតុងអាចចុចមុនដើរ ដើម្បីបើកមុខងារហៅរែក ប៉ុន្តែមិនទាន់ចាប់ផ្តើមរហូតដល់កូនទ័ពគោលដៅដើរចូលក្រឡាថ្មី។
4. ឬដើរកូនទ័ពសិន ហើយចុច «ហៅរែក» នៅពេលត្រូវការ។
5. ហៅបានតែកន្លែងដែលកូនទ័ពទើបដើរចូល។
6. បើមានកូនគូប្រកួតអាចមករែក -> ហៅរែកចាប់ផ្តើម ហើយប៊ូតុងបិទ ខណៈរង់ចាំគូប្រកួតឆ្លើយតប។
7. បើគូប្រកួតចូលមករែក -> បន្ទាប់ពីការរែករួច វេនត្រឡប់មកអ្នក ហើយប៊ូតុងហៅរែកបង្ហាញឡើងវិញ។
8. បើគ្មានកូនគូប្រកួតអាចមករែក -> ហៅរែកអាសាបង់ ប៊ូតុងបិទ ហើយវេនទៅគូប្រកួតធម្មតា។
9. ប៊ូតុងនឹងរង់ចាំរហូតដល់វេនអ្នកមកដល់ម្តងទៀត។
10. រែក ព័ទ្ធ ស្តេច និងច្បាប់ផ្សេងៗរក្សាដដែល។
