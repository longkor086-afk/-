លេងរែក V19 — ហៅរែកជាជម្រើសពិតប្រាកដ

- ដើរកូនធម្មតា -> មិនចាំបាច់ចុច «ហៅរែក» ទេ។ វេនប្តូរទៅគូប្រកួតភ្លាម។
- ប៊ូតុង «🪤 ហៅរែក» គឺជាជម្រើសសម្រាប់ពេលអ្នកចង់ប្រើល្បិចហៅរែក។
- បើចង់ហៅរែក -> ចុចប៊ូតុងមុនដើរ -> បន្ទាប់មកដើរកូនទ័ពគោលដៅ។
- ពេលកូនគោលដៅដើរចូលក្រឡាថ្មី ប្រព័ន្ធទើបពិនិត្យការហៅរែក។
- បើមានកូនគូប្រកួតអាចមករែក -> ហៅរែកចាប់ផ្តើម។
- បើគ្មាន -> ហៅរែកអាសាបង់ ហើយគូប្រកួតបានវេនធម្មតា។
- មិនមានការបង្ខំឱ្យចុច «ហៅរែក» បន្ទាប់ពីដើរទេ។
