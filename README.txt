លេងរែក V18 — ហៅរែកជាជម្រើស មិនបង្ខំ

- ដើរកូនធម្មតា -> មិនចាំបាច់ចុច «ហៅរែក» ទេ។
- ប៊ូតុង «ហៅរែក» មានសម្រាប់ប្រើតែពេលអ្នកចង់ដាក់អន្ទាក់។
- បើចង់ហៅ: បន្ទាប់ពីកូនទ័ពគោលដៅទើបដើរ ចុច «ហៅរែក» ហើយប្រព័ន្ធពិនិត្យកន្លែងនោះ។
- បើគ្មានកូនអាចមករែក -> ហៅអាសាបង់ ហើយគូប្រកួតដើរធម្មតា។
- បើមិនចង់ហៅ: មិនចាំបាច់ចុចប៊ូតុង។ ចុចក្រឡាផ្សេង/កូនផ្សេង ដើម្បីបញ្ចប់ឱកាសហៅរែក ហើយប្តូរវេន។
- ប៊ូតុងមិនត្រូវបានប្រើជាប៊ូតុង «បន្ត» ទៀតទេ។
