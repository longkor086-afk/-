លេងរែក V11

រក្សាទុកច្បាប់ V10 ទាំងអស់ ដែលអ្នកបានបញ្ជាក់ថាដំណើរការ 100%។

បន្ថែមច្បាប់ស្តេច:
- បន្ទាប់ពីដំណាក់កាលចេញកូន ២ ចប់ ស្តេចអាចដើរដូចកូនទ័ព។
- ស្តេចអាចដើរតាមជួរឈរ និងជួរដេក ដោយមិនគិតចម្ងាយ ដូចកូនទ័ព។
- ស្តេចអាចដើរចូលក្រឡាដែលបង្កើតរែក។
- ស្តេចអាចរែកកូនគូប្រកួតបាន។
- ស្តេចអាចចូលទៅជាប់ក្រុមគូប្រកួត ហើយបង្កើតការព័ទ្ធបាន។
- ស្តេចក៏អាចត្រូវគូប្រកួតរែកបាន; បើស្តេចត្រូវរែក -> ចាញ់។
- ស្តេចក៏អាចត្រូវគូប្រកួតព័ទ្ធបាន; បើស្តេចនៅក្នុងក្រុមដែលគ្មានប្រឡោះ -> ចាញ់។
- ច្បាប់ "ជ្រើសកូន ២" នៅដើមហ្គេមនៅតែសម្រាប់កូនទ័ពប៉ុណ្ណោះ មិនរាប់ស្តេច។
