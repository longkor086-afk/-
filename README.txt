លេងរែក V12 — ហៅរែក

រក្សាទុក V11 ទាំងអស់:
- រៀបកូន 16/16
- ចេញកូន 2 ដំបូង
- រែក
- ព័ទ្ធជាក្រុម
- ស្តេចដើរ/រែក/ព័ទ្ធ

បន្ថែម «ហៅរែក»:
1. អ្នកលេងអាចលះបង់កូនទ័ពដោយធ្វើចលនាដែលបង្កើតឱកាសឱ្យគូប្រកួតរែកកូនទ័ពនោះ។
2. ប្រព័ន្ធស្វែងរកចលនារបស់គូប្រកួតដែលអាចរែកកូនដែលត្រូវបានហៅ។
3. បើមាន 2 ឬច្រើនជម្រើស គូប្រកួតអាចជ្រើសកូនណាមួយ។
4. បើគ្មានជម្រើសរែក -> មិនចាត់ទុកជាហៅរែក ហើយលេងធម្មតា។
5. បន្ទាប់ពីគូប្រកួតឆ្លើយតបការហៅរែក វេនត្រឡប់ទៅអ្នកដែលបានហៅ។
6. ស្តេចមិនត្រូវបានប្រើជាកូនលះបង់សម្រាប់ហៅរែក។
7. បើការរែកក្នុងការឆ្លើយតបប៉ះស្តេច -> ភាគីស្តេចចាញ់។
