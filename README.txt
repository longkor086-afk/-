លេងរែក V13 — ហៅរែកដោយប៊ូតុង

រក្សាច្បាប់ V12 ទាំងអស់។

កែសំខាន់:
1. ប្រព័ន្ធលែងចាប់ "ហៅរែក" ដោយស្វ័យប្រវត្តិទៀតហើយ។
2. បន្ទាប់ពីកូនទ័ពដើររួច អ្នកលេងត្រូវជ្រើសកូនទ័ពដែលទើបដើរ។
3. ប៊ូតុង «🪤 ហៅរែក» នឹងបង្ហាញ។
4. ពេលចុចប៊ូតុង ប្រព័ន្ធគណនាថាគូប្រកួតមានកូនណាអាចចូលមករែកកូននោះបាន។
5. បើមាន 1 ឬច្រើនជម្រើស -> ការហៅរែកកើត ហើយគូប្រកួតអាចជ្រើសកូនណាមួយក្នុងចំណោមជម្រើស។
6. បើគ្មានកូនគូប្រកួតអាចមករែក -> ប៊ូតុងមិនអនុវត្តការហៅរែក ហើយបង្ហាញថាមិនអាចហៅបាន។
7. «ហៅរែក» ប្រើសម្រាប់កូនទ័ពដែលទើបដើរ មិនប្រើស្តេចជាកូនលះបង់។
8. រែក/ព័ទ្ធ/ស្តេច និងច្បាប់ផ្សេងទៀតរក្សាដដែល។
