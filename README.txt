លេងរែក V2

កែតម្រូវតាមច្បាប់ដែលបានបញ្ជាក់៖
1. រែកកើតឡើងតែពេលកូន "ទើបដើរចូល" ទៅក្នុងប្រឡោះដែលមានកូនគូប្រកួតនៅជាប់ខាងទាំងពីរ។
2. រែកបានទាំងជួរដេក និងជួរឈរ។
3. រែកមួយលើកសម្លាប់តែ ២ កូនដែលនៅសងខាងកូនដែលទើបដើចូល។
4. មិនសម្លាប់កូនផ្សេងទៀតដែលនៅជិត។
5. បើកូនគូប្រកួតនៅតែម្ខាង ឬគ្រាន់តែដើរចូលនៅខាងក្រៅប្រឡោះ នោះមិនមានរែក។
6. ដំណាក់កាលបើកឆាកត្រូវរៀបចំការចេញកូន ២ សម្រាប់ឱ្យភាគីទាំងពីរបានរែកគ្នា មុនចូលលេងធម្មតា។

ចំណាំ៖ ច្បាប់បើកឆាកនៅក្នុង V2 នៅតែជាការរៀបចំតាមការពិពណ៌នា ហើយអាចកែឱ្យជាចលនាបង្ខំជាក់លាក់ ប្រសិនបើមានលំដាប់ក្រឡាដែលអ្នកចង់កំណត់។
