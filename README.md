# លេងរែក — Version 1

គម្រោង HTML + CSS + JavaScript សម្រាប់ហ្គេមរែកលើក្តារ ៨×៨។

## បើកលេង
បើក `index.html` ក្នុង Browser។

## ឯកសារ
- index.html — ផ្ទាំងហ្គេម
- style.css — រូបរាង និង Font
- game.js — ក្តារ កូន និងការដើរ

## ចំណាំ
Version 1 នេះផ្តោតលើក្តារ 8×8, កូន 15 + ស្តេច 1, ការដើរតាមជួរដេក/ជួរឈរ និងគ្រោងច្បាប់ព័ទ្ធ។
ច្បាប់ "រែក", "ហៅរែក", និងលក្ខខណ្ឌ 64 ដង ត្រូវកំណត់ជាក់លាក់បន្ថែម មុនដាក់ជា game engine ពេញលេញ ដើម្បីកុំឱ្យកូដបកស្រាយខុសពីច្បាប់ដែលអ្នកចង់បាន។


## កែសម្រួលតាមច្បាប់អ្នក
- នៅដំណាក់កាលចាប់ផ្ដើម ភាគីទាំងពីរត្រូវដើរម្នាក់មួយដងសិន ដើម្បីរៀបចំការរែក។
- បន្ទាប់ពីភាគីទាំងពីរបានដើរម្នាក់មួយដងហើយ ទើបចូលដំណាក់កាលដើរធម្មតា។
- ការរែកក្នុង Version នេះកំណត់ជា "ជួរឈរ/បញ្ឈរ" តែប៉ុណ្ណោះ។
- ការរែកតាមជួរដេក/ផ្ដេក មិនត្រូវបានរាប់ជារែកទេ។


## កែតម្រូវតាមច្បាប់ថ្មី
- សងខាងមាន ១៥ កូនទ័ព + ស្តេច ១។
- ដំណាក់កាលចាប់ផ្តើម៖ ភាគីទាំងពីរដើរ **កូនទ័ព ២ ដងម្នាក់** ដោយឆ្លាស់គ្នា (សរុប ៤ វេន) មុនចូលលេងធម្មតា។
- ក្នុងដំណាក់កាលនេះ ស្តេចមិនអាចដើរ។
- ការរែកក្នុង Version នេះគិតតែ **ជួរឈរ/បញ្ឈរ**។ ការរែកតាមជួរដេក/ផ្ដេកមិនរាប់ទេ។
- ក្តារចាប់ផ្តើមមានបន្លោះទំនេរតាមទម្រង់កូន ១៥ + ស្តេច ១ ម្នាក់ៗ។
