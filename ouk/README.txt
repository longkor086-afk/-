OUK KHMER — CLEAN NEW VERSION
==============================

Files:
- index.html
- style.css
- game.js

There are NO external libraries and NO extra JavaScript dependencies.

How to use:
1. Put all 3 files in the same folder.
2. Open index.html.
3. Upload the 3 files to GitHub Pages in the same folder.

Important:
This version implements the core Ouk Chaktrang movement rules, check,
checkmate, stalemate, clocks, first-move special rules, and pawn promotion.

The traditional endgame counting rules (Viel L'koun / Viel K'dar) are not
implemented yet, so this should not be advertised as a complete tournament
rules engine until those counting rules are added and tested.
