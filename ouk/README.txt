OUK KHMER 2D – UPDATED

Main corrections:
1. Board is a strict 8x8 square grid: every row and column is equal.
2. Khmer-style 2D vector pieces are drawn inside the game; no external image/font assets.
3. Trey (ត្រី) has no double-step and no en-passant.
4. White Trey promotes on rank 6; Black Trey promotes on rank 3. The promoted piece is Trey Bak (ត្រីបក), which moves exactly like Neang (one diagonal square), not like an international chess queen.
5. Neang moves one diagonal square. On its first move, before any capture, it may move two squares straight forward if both squares are empty; it cannot capture with this special move.
6. Koul moves one diagonal square or one square forward.
7. Ses moves like an international chess knight.
8. Tuuk moves like a rook.
9. King moves one square in any direction. On its first move, before any capture and only when not in check, it may make a knight move; the special knight move may capture an enemy piece.
10. Check and checkmate legality is enforced.
11. 3:00 + 2 seconds timer retained.
