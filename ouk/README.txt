OUK KHMER - RULE + BOT UPDATE

Main fixes:
1. Trey promotion is now on the opponent's original Trey rank:
   - White Trey: row 3 (same row where Black Trey starts)
   - Black Trey: row 6 (same row where White Trey starts)
2. Promotion changes Trey into Neang (using the existing Neang/queen artwork).
3. No two-square Trey move and no en-passant.
4. Added playable Bot mode (default: White human vs Black bot).
5. Bot uses alpha-beta minimax, move ordering, material/position/mobility evaluation and tactical promotion priority.
6. Bot can be turned off to play human vs human.
7. Existing 2D wooden board and piece assets are preserved.
