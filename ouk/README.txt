OUK WOOD 100% PIECE REFERENCE
==============================

This project uses transparent PNG assets cropped directly from the supplied
reference screenshot. The piece artwork is not Unicode and is not redrawn
with CSS.

Files:
- index.html
- style.css
- game.js
- assets/*.png

Upload all files together. Do not keep an older game.js/style.css in the same
folder if you want this version to run unchanged.

The game board and interface are responsive for mobile screens.
